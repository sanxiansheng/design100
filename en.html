QUICK START

Connect your design in three steps.

  1. 01

    Install the plugin and companion

    Download and unzip the plugin. In the Figma desktop app, go to Plugins → Development → Import plugin from manifest, then select manifest.json from the extracted folder. Get and launch the design100 Mac companion app.

  2. 02

    Copy the pairing code and connect

    Copy the pairing code from the design100 desktop app. Open the design100 plugin in Figma, paste the code and connect. Keep both apps open during pairing.

  3. 03

    Select a design and start an export

    Select a frame, component or layer in Figma and wait for the preview in the desktop app. Start the export there, then hand the resulting design package to your AI development tool.

GOOD TO KNOW

A few things to know before you start.

Do I need to install from Figma Community?

This website provides a beta package for manual import through the Development menu in the Figma desktop app. The public availability of the Community version has not been confirmed. Use the download and setup instructions on this page.

Does it generate website code directly?

No. design100 prepares design data, assets, implementation guides and verification tools. Give the exported package to your own AI development tool to implement the frontend.

Why do I need the Mac app? Does it work on Windows?

Exports are started from the design100 Mac app. The Figma plugin reads your selection and generates the design package. The current workflow requires a Mac; a Windows companion app is not available yet.

What if pairing gets stuck or an export times out?

Make sure the desktop app is running, copy a fresh pairing code, then close and reopen the Figma plugin. Allow Figma local network access if prompted. Export timeouts are a known beta issue. Try a smaller selection and email the error message to support. Do not send pairing codes or sensitive design files.

Where does my design data go?

The plugin exchanges selection data and previews with the companion through localhost:38472 on your machine. Exported packages contain the selected design and assets. The plugin does not call remote AI services. You decide what to share with third-party AI tools. For details, read the product privacy policy.
